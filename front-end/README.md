# ArtEventManager

A web app for managing art events, tracking cultural events happening in Brussels, and connecting with friends.

## Tech Stack
- React (frontend)
- Node.js (backend)

## Getting Started

### Install dependencies
```bash
npm install
```

### Run the app
```bash
npm start
```

## Environment Variables
Create a `.env` file in the backend with:
```
PORT=
DB_CONNECTION=
JWT_ISSUER=
JWT_AUDIENCE=
JWT_SECRET=
```
